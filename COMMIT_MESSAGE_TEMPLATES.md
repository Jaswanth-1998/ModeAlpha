## Reusable Pattern Templates

### New feature

```bash
git commit -m "feat(module): add short feature description"
```

### Bug fix

```bash
git commit -m "fix(module): resolve short issue description"
```

### Refactor

```bash
git commit -m "refactor(module): improve code structure for maintainability"
```

### Documentation update

```bash
git commit -m "docs(module): update setup and usage guidance"
```

### Maintenance update

```bash
git commit -m "chore(module): update configuration or support tooling"
```

## Best Use Tip

If one commit contains many related changes, prefer:
- one strong subject line
- one short explanatory body

This gives better tracking in team and corporate environments.
